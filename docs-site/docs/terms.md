# AiCode 用户协议

**最后更新：2026 年 10 月 23 日**

AiCode（以下简称“本应用”）是一款运行在 Android 上的开源 AI 编程工具，由 jieapi（个人开发者，以下简称“开发者”）维护。本协议说明使用本应用时的权利、义务及重要风险，请结合[隐私政策](/privacy)阅读。

## 一、阅读与确认

使用本应用前，请阅读本用户协议和隐私政策，再决定是否同意。选择“同意并继续”后，应用会保存你的确认状态；选择不同意则退出应用。

你可以通过“设置 → 关于”中的“用户协议”和“隐私政策”入口随时查看全文。

本协议适用于本应用的使用，不替代第三方服务条款，也不限制你依法或依据 GPL-3.0 享有的权利。

## 二、功能与 AI 生成风险

本应用提供 AI 对话与编程辅助、文件编辑、终端与本地 Linux 容器、Git、远程 SSH、浏览器、MCP、技能、子代理及备份等功能。具体可用能力取决于设备、配置、权限和所连接的服务。

AI 生成的代码、命令、解释、图片及其他内容可能存在错误、遗漏、安全漏洞、侵权风险或不适合你的实际场景。AI 回复不是对准确性、安全性、合法性或适用性的保证，也不应替代必要的专业判断。请在采用、执行、发布或部署前自行审查，并按需测试、核实来源及取得授权。

AI 和工具可能在你选择的运行模式及授权范围内读取、修改、覆盖或删除文件，执行命令、安装依赖、访问网络、操作 Git 仓库，以及连接或修改远程服务器。部分操作可能连续执行，并非每一步都会单独请求确认。

错误指令、模型判断失误、不可信项目内容或第三方工具可能导致数据丢失、凭据泄露、服务中断、配置损坏或意外费用。权限控制、检查点和撤销功能不能保证防止或恢复所有损失；本地容器也不等于对已挂载目录、网络资源或远程服务器的绝对隔离。

请确认目标设备、目录、仓库和服务器的操作权限，按需限制工具授权；对删除、覆盖、推送、部署、系统命令及生产环境操作尤其谨慎。不要把不希望发送给第三方的秘密放入 AI 可读取的文件、规则或命令输出中。
