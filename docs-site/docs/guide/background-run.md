# 后台运行

「设置 → 后台运行」集中管理 App 在后台的运行与提醒行为。

## 后台运行保活

开启后显示一个前台通知，避免 App 退到后台时进程被系统终止。即使没有任何终端会话、AI 也空闲，进程同样保持存活；进程被系统回收重建后会自动恢复这个常驻状态。点通知可以回到 App 主页。

运行编译这类长任务前建议开启。

::: tip AI 执行期间会自动保活
即使该开关关闭，AI 开始执行任务时也会自动亮起同一个常驻通知并保持 CPU 唤醒（避免熄屏后回复中断、工具卡住），所有会话的任务结束后自动收起。手动打开开关的意义在于「空闲时也常驻」：希望终端里自行运行的后台命令不被打断，就保持开启。开关开启时，AI 任务结束不会将其关闭。
:::

## 屏幕常亮

开启后只要 App 停留在前台，屏幕就不会自动息屏，适合持续观察 AI 任务或终端输出。切到其它 App 或回桌面后自动失效，不影响系统的自动锁屏设置，也不需要额外授权。

长时间开着会多耗电，插着充电器用更合适。

## Agent 完成通知

开启后，当 App 在后台、AI 完成一轮对话时会弹系统通知（标题「任务完成」，内容是你发的那条消息；如果是后台任务触发的自动轮次，显示对应的任务标题），点通知回到 App 看结果。

App 在前台时不弹，避免打扰你正在看的对话。

## 实时通知

开启后，AI 在后台工作时会显示一条实时进度通知，内容是当前正在做的事（「正在思考」「正在联网搜索」「正在执行命令」等）。多个会话同时运行时合并成一条，逐行列出每个会话的状态。回到前台、或所有任务结束后自动收起。

只在 App 处于后台时显示，你正在看的对话不会被打扰。

通知能否被系统提升到状态栏、锁屏（部分机型表现为顶部「岛」），取决于系统版本：**Android 16 及以上**（例如 ColorOS 16）会把它当作实时通知展示；更低版本只显示为普通通知。

## 授权审批通知

开启后，当 App 在后台、AI 有阻塞等待你处理的确认时会弹系统通知，包括三种情况：请求工具授权（如执行命令、改写文件）、向你提问、退出计划模式等待计划审批。多个会话同时等待时合并成一条，逐行列出各自的状态（「需要授权」「需要回答」「等待计划审批」）。点通知回到 App 处理，处理完或回到前台后自动收起。

只有**一个**待处理项时，通知上会直接带按钮：工具授权显示「拒绝」「允许」（「允许」只放行本次、不记忆规则），计划审批显示「批准」「拒绝」，点一下即可完成审批，不必回到 App。若同时有多个会话待处理、或待处理的是向你提问，则只显示内容，点通知回到 App 处理。按钮只针对通知所对应的审批请求；请求已取消或处理完时，旧按钮不会批准后来的请求。

App 在前台时不弹，避免打扰你正在看的对话。

::: tip Android 13 及以上
首次开启需要通知权限的开关（后台运行保活、Agent 完成通知、实时通知、授权审批通知）时会先申请「通知」权限。如果系统弹不出授权框（权限之前被关过或拒绝过），会有弹窗提示，点「去设置」跳到系统设置页手动开启。权限授予前开关不生效。
:::

系统权限（安装未知应用、存储、电池优化、自启动、Shizuku）见[软件权限](/guide/app-permissions)。

## 切到后台后断网怎么办

把 App 切到后台一段时间后，AI 对话可能中断并提示「网络连接断开」。这是 Android 为省电对后台应用的正常限制：应用不在前台时，系统会**冻结**它的进程，冻结期间收不到也发不出数据，已经建立的网络连接也会被切断。这与屏幕是否熄灭无关。

**注意**：把系统的省电策略改成「无限制」通常解决不了这个问题——它只解除「低电耗 / 应用待机」限制，管不了进程冻结；而且屏幕没熄时系统根本不会进入低电耗，改它也看不出效果。

按下面的顺序设置，多数情况都能明显改善：

1. **打开上面的「后台运行保活」**，并保留通知栏的常驻通知（不要关掉它）。
2. **在多任务界面给本应用加锁**（各机型操作见下），不要直接把它划掉——直接划掉常常等同于强制停止。
3. **在系统设置里把本应用设为「无限制 / 不优化」，并允许自启动**。

### 常见品牌设置路径

不同品牌的后台与省电入口位置不同，找不到时可在系统设置顶部搜索「自启动」「后台」「省电」等关键词。

| 品牌 | 关键路径 |
| --- | --- |
| 华为 / 荣耀 | 应用启动管理 → 关闭自动管理 → 在「手动管理」里打开「允许自启动」「允许关联启动」「允许后台活动」；多任务卡片下拉加锁 |
| 小米 / Redmi | 省电与电池 → 右上角设置 → 应用智能省电 → 选本应用 → 无限制；应用设置 → 授权管理 → 自启动管理；多任务长按卡片加锁 |
| OPPO / 一加 / realme | 应用 → 应用管理 → 本应用 → 电池使用情况 → 允许后台活动；应用 → 自启动；电池 → 更多设置 → 优化电池使用 → 不优化；多任务卡片加锁 |
| vivo / iQOO | 应用与权限 → 权限管理 → 所有权限 → 自启动；电池 → 后台耗电管理 → 允许后台高耗电；多任务卡片加锁 |
| 三星 | 电池和设备维护 → 电池 → 后台使用限制 → 把本应用加入「从不休眠」；应用程序 → 本应用 → 电池 → 不受限制 |
| 原生 Android 等 | 电池 → 电池优化 → 本应用 → 不优化；若熄屏也断，WLAN → 高级 → 休眠状态保持 WLAN 连接 → 始终 |

各品牌路径会随系统版本变化，以手机实际界面为准。

### 还有几个可能原因

- 有的系统会在省电策略之外，**单独限制后台应用的联网**，请确认本应用未被禁止后台联网。
- 手机开机两三天后后台管理会变严，此时重启一次手机往往能明显改善。
- **AI 长回答在后台中断属于可预期情况**：模型长时间没有输出时，网络中间的网关可能把空闲连接断开，这一点 App 无法完全避免；回到前台后会自动重试。
