# 关于与更新

「设置 → 关于」显示应用信息，也是检查更新的入口。

## 版本与检查更新

顶部卡片显示 App 图标、应用名和一句简介，下面的「版本」行显示当前版本号。

**点版本行手动检查更新**：会查询 GitHub 发布列表是否存在更高版本（按你选的更新通道过滤）。有新版本时弹窗显示「发现新版本」，并列出**从你当前版本到最新版本之间的全部更新日志**；点「下载并安装」会在应用内下载匹配你设备架构的安装包（默认走加速镜像），校验通过后直接调起系统安装器——首次需要你允许 App「安装未知应用」，授权后回到 App 再点一次「安装」即可，安装包已经下载好，不会重下。

下载过程中关掉弹窗不会中断，再点一次「版本」行就能回到进度界面。下载失败时弹窗会说明原因，可以点「重试」，也可以改用「浏览器下载」自己去 Release 页面拿包。

已经是最新版会提示「已经是最新版本」；网络失败会提示「检查失败」并给出错误信息。

若提示**安装包签名与当前应用不一致**，说明这个安装包不是当前 App 的签名（例如从其它渠道安装的版本），只能用「浏览器下载」手动处理，应用内更新不会覆盖安装。

## 自动检查更新

默认开启。打开 App 进主页时在后台异步检测，**每天最多一次**（当天检测过即不再重复）。发现新版本会自动弹出更新窗，网络失败时静默处理，不打扰你。

关闭之后不再自动检测，但手动点版本行仍然可以检查。

## 更新通道

默认「稳定版」：

- **稳定版**：只检测正式版，过滤掉 RC 预览版。
- **最新版**：包含 RC 预览版。

如需体验新功能可切换到最新版，偏好稳定则留在稳定版。

无论选哪个通道，下载的都是弹窗里那个版本自己的安装包：选最新版通道检测到 RC 预览版时，拿到的就是该 RC 的包，不会落到旧的稳定版上；点「浏览器下载」时也按该版本的 tag 直达对应 Release 页面。

## 下载镜像源

更新包默认从 `cdn.gh-proxy.com` 这个 GitHub 加速节点下载（`github.com` 直连在国内经常很慢甚至超时）。在同一页点「下载镜像源」可以改：

- **gh-proxy CDN**：默认节点。
- **gh-proxy 优选节点**：同项目的另一个节点，网络环境不同时可能更快。
- **直连 GitHub**：不使用镜像，直接从 `github.com` 下载。
- 也可以自己填任意加速前缀（形如 `https://你的镜像/`），支持 `{url}` 占位符写法。

镜像不可用时 App 会自动改用直连重试一次，所以填错也不会把更新卡死，只是多花一点时间。填完记得点「保存」。

## 其它入口

- **GitHub 仓库**：用系统浏览器打开源码仓库。
- **开源许可证**：本项目使用 GPL-3.0，点击打开完整的 LICENSE 文件。
- **用户协议**：用系统浏览器打开[用户协议](/terms)，了解使用规则、AI 与操作风险、第三方费用及开源权利。
- **隐私政策**：用系统浏览器打开[隐私政策](/privacy)，了解数据保存、联网传输、日志与备份的处理方式。

## 首次启动确认

首次启动 App 时，协议确认弹窗覆盖在主界面上，其中包含「用户协议」和「隐私政策」两个蓝色链接。点击任一链接，会使用系统浏览器打开对应全文；阅读后返回 App 再决定是否同意。确认状态读取期间主界面保持显示；首次引导和自动检查更新在同意后启动。

- **不同意**：退出应用。
- **同意**：继续使用，并记住确认状态，之后启动不再重复提示。

如需再次阅读，可随时进入「设置 → 关于」，分别点击「用户协议」或「隐私政策」。
