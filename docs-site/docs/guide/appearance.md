# 外观与语言

「设置」首页点「外观主题」「背景图」或「语言」会弹出底部选择窗口，选择后立即生效并保存。

## 外观主题

面板里分三块：明暗模式、配色方案、莫奈取色。选择后不会自动关窗，便于连续对比多套配色。

### 明暗模式

三选一：跟随系统、固定深色、固定浅色。

### 配色方案

四套预设，深浅两种模式各自配好：

- **默认蓝**：App 默认的蓝色调。
- **咖啡**：暖赤陶色 + 米白纸感底。
- **石墨**：中性冷灰，颜色干扰最小。
- **森林**：低饱和绿。

色块外圈是该主题的页面底色、内圈是主色，预览会跟随当前明暗模式变化。

Git 泳道色、日志级别色、diff 增删的红绿属于功能标识，不随主题变化，避免同一含义在不同主题下颜色不一致。代码编辑器的语法高亮与终端配色也是各自独立的设置。

### 莫奈取色

开启后从系统壁纸提取配色，上方所选的配色方案不再生效（色块变灰）。默认关闭。

需要 Android 12 及以上系统；低版本设备上开关不可用，描述会直接提示。壁纸调色板由系统生成，不同手机厂商的取色结果差异较大，效果不满意关闭即可。

## 自定义背景图

可以设置一张全局背景图：

- **选择图片**：从系统相册选一张作为 App 全局背景，叠在所有页面内容上（水印效果，不拦截触摸）。终端页保持纯黑底，不显示背景。
- **透明度**：滑块显示 0% 到 100%，实际生效范围映射到 0% 到 20%（即滑到 100% 相当于 20% 不透明度），以保证文字始终可读。默认 15%，拖动实时生效。
- **移除背景**：恢复默认纯色背景。

背景图文件保存在应用私有目录，**不随备份导出**，更换设备需要重新设置。

## 语言

可以跟随系统语言，也可以直接指定一种已支持的语言。

## 终端外观

终端的配色主题、字体、字号、光标样式是单独一套设置，见[终端](/guide/terminal#外观设置)。
