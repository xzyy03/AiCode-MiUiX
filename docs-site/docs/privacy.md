# AiCode 隐私政策

**最后更新：2026 年 10 月 23 日**

AiCode（以下简称“本应用”）是一款运行在 Android 上的开源 AI 编程工具（GPL-3.0 协议）。本政策说明本应用如何处理你的信息。

**开发者不通过自营业务后端收集或集中保存你的聊天、工作区文件和凭据，也不出售这些数据。** 本应用主要在设备本地保存配置和会话，但这不意味着所有数据都只在本机处理：使用 AI、联网搜索、远程服务器、远程备份等功能时，相关内容会发送到相应服务；应用也会为更新和获取公开配置发起网络请求。

## 一、账号与信息收集

- 本应用**不设自有账号系统**，无需注册 AiCode 账号。GitHub 等第三方集成功能可能需要登录或授权相应服务，并在设备上保存授权凭据。
- 本应用**不内置统计、埋点、广告或崩溃上报 SDK**，不会为使用分析或广告目的自动上传你的操作记录、聊天内容或日志。
- 应用会在本地记录运行和崩溃诊断信息，详见第二节；本地记录不等于自动上传。
- 开发者不会通过本应用远程读取你的设备数据。如果你主动提交 Issue、复制崩溃信息或分享日志，其中的内容会提供给你选择的接收方；请先检查并移除敏感信息。

## 二、数据的保存位置与日志

本应用处理的数据包括：

- **配置与凭据**：模型供应商、API Key、服务端点，以及你配置的服务器、Git、备份等连接和授权信息。
- **聊天与 AI 上下文**：聊天记录、会话历史、附件、项目规则、记忆及工具执行结果等。
- **工作区与环境文件**：代码、文件、容器镜像和本地 Linux 环境数据。
- **偏好设置、诊断日志与备份文件**。

配置和会话等数据主要保存在应用私有存储中；日志可能保存在应用专属的外部存储目录。默认本地工作区位于应用私有目录，但你选择的**外部工作区**保存在相应设备目录中，**远程工作区**保存在目标服务器上。导出文件和备份保存在你选择的位置，不一定处于应用私有目录。

**日志可能包含敏感内容。** AI 请求与响应日志会记录请求地址、对话上下文、代码、工具结果、模型回复和错误信息等。应用会对部分媒体内容作脱敏处理，但**不保证识别或移除文本、网址及工具输出中的密码、令牌或个人信息**。崩溃诊断还可能包含设备型号、系统版本、内存情况和错误堆栈，不会自动上报。

运行日志和 AI 日志设有容量限制及旧文件清理机制；初始化日志时会清理超过 7 天未更新的相应日志文件。这不是所有数据在 7 天后必然删除的承诺，仍在更新的日志、会话、导出副本和备份有各自的生命周期。删除聊天也不等于同步删除已经生成的日志或备份。

## 三、联网与向第三方传输数据

### 基础联网请求

- **公开配置与目录**：应用启动时会根据缓存情况获取模型元数据、供应商预设和容器镜像目录，请求可能经过 GitHub 及 jsDelivr 等分发节点。这些请求用于下载公开数据，不附带你的聊天、工作区内容或 API Key。
- **检查与下载更新**：自动检查更新默认开启，可在设置中关闭。检查会请求 GitHub Releases 接口；更新包下载可能经过设置中的第三方镜像，默认使用 gh-proxy 镜像，也可修改或留空以直连 GitHub。
- **环境与网络功能**：下载容器镜像、安装软件包或使用开发工具时，会访问相应镜像站、软件仓库或目标服务；代理连通性检测也可能请求外部检测站点。

这些服务及网络中间节点可能收到 IP 地址、请求时间、请求头和资源路径等网络信息。**不上传聊天内容并不等于不产生网络信息。**

### 使用功能产生的数据传输

- **AI 模型供应商**：对话内容及相关上下文会发送到所选模型服务。除你手动发送的代码、文件和图片外，上下文还可能包括自动加载的项目规则、记忆与技能清单，以及 AI 通过工具读取的文件、命令输出和其他执行结果。标题生成、上下文压缩等辅助 AI 功能也可能提交相关内容。生图功能使用你为其配置的模型服务，可能与对话供应商不同，并可能从服务返回的地址下载图片。
- **联网搜索、网页抓取与浏览器**：内置联网搜索会将查询内容发送到 Parallel 的搜索服务；网页抓取和浏览器会请求目标网站。浏览器将非网址输入作为搜索词时，会发送到默认搜索引擎 Bing。查询、网址或页面交互可能包含你或 AI 提供的信息。
- **MCP 服务**：调用 MCP 工具时，相应参数会交给你配置的本地进程或远程服务器；本地 MCP 进程也可能自行联网。工具返回的结果可能继续进入 AI 上下文。
- **远程服务器与开发服务**：SSH、SFTP、Git 以及终端中的联网命令会向相应服务器传输认证信息、命令、文件或仓库内容。GitHub 授权会与 GitHub 交换授权信息，并获取所需的账号或安装信息。开启凭据注入时，相关凭据也会写入对应的本地环境或远程服务器。
- **远程备份**：你可以将所选备份内容上传到配置的 WebDAV 或 S3 兼容存储。备份可能包含会话、配置、凭据或工作区文件，具体以导出时选择的范围为准；备份加密说明见第五节。
- **文件共享**：开启内置 FTP 服务后，获准连接的客户端可以访问共享目录，并可能具有写入权限；启用匿名访问会扩大可访问范围。通过系统文件选择器授权其他应用访问工作区，或主动分享文件时，相应内容也会提供给接收方。

第三方对数据的保存、使用、删除及可能的跨境处理，受其政策和你与其约定的条款约束。请在使用前了解相应服务的数据处理方式，不要把不希望外发的秘密放入 AI 可读取的文件、规则或命令输出中。

## 四、权限说明

本应用根据功能使用网络、存储、通知、前台服务、唤醒锁等权限，并可能请求安装未知应用、忽略电池优化等特殊访问权限。Shizuku 功能需要你额外授权，授权后可用于执行系统命令。

网络等部分权限由系统在安装时授予，不会逐次弹窗；需要运行时授权或特殊访问授权的功能，会按系统机制申请。你可以拒绝或撤销相应授权，但依赖这些授权的功能会受到影响。详细说明见[软件权限](/guide/app-permissions)。

## 五、数据安全与备份

- 应用私有数据受 Android 应用沙盒等机制保护，但这不是对 Root、设备被攻破、系统缺陷或你主动授权共享等情形的绝对保障。外部目录、远程服务器和导出文件的安全还取决于相应环境。
- API Key 等部分敏感配置使用 Android Keystore 相关机制保护；这不代表所有凭据、日志、环境文件或备份都经过加密。提供给开发工具使用的凭据可能以工具所需格式写入本地环境或远端。
- **备份加密是可选的。设置密码后，导出内容会加密；未设置密码时，备份文件本身不加密。** 远程备份同样遵循此规则，压缩打包本身不能保护内容。请为包含敏感信息的备份设置强密码，并妥善保存密码。
- 自定义 HTTP 端点、普通 FTP 或其他未加密连接可能使内容在传输中暴露。请优先选择支持加密传输的服务，并谨慎授权 AI 工具、第三方进程与文件共享功能。

## 六、数据删除

- 你可以在应用内删除聊天、配置或工作区，并通过相应文件管理和日志功能清理不再需要的数据。
- **卸载本应用或清除应用数据会清除应用私有数据，但不等于删除所有相关副本。** 外部工作区文件、导出文件、下载文件以及你保存到其他位置的备份，可能仍然保留，需要另行清理。
- 移除外部工作区通常只解除应用与目录的关联，不删除其中的文件。远程工作区和远程备份也不会因卸载应用而自动删除；如需删除，请在卸载前通过相应功能或直接登录目标服务处理。
- 已发送给 AI、搜索、MCP 等第三方的数据，不会随本地删除自动从第三方清除，需按照相应服务的规则处理。已主动公开或分享的日志与文件，也可能存在其他副本。
- 开发者没有集中保存上述会话和工作区的数据副本，无法代替你删除设备或第三方服务中的数据。若你曾主动向开发者提交资料，可通过下述联系方式咨询处理方式。

## 七、儿童隐私

本应用面向具备开发能力的用户，不面向儿童，也不会故意通过自营服务收集儿童的个人信息。使用第三方服务时，还应遵守其年龄要求和隐私政策。
