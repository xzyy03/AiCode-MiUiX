## How it works

1. Each row is one prompt fragment: the leading number sets its order in the system prompt, and the badge on the right shows which layer this copy comes from.
2. Only one copy per number takes effect, with priority Project > Global > Local > Built-in.
3. Tap a row to edit its content; swipe left to delete the override in the writable layer, which falls back to the next layer.
4. Tap the + button in the top bar to add a fragment with a free number, or open Advanced.
5. Changes take effect immediately — no app restart needed.
